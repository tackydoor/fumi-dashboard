# MyDashboard

ブラウザだけで動くダッシュボードです。サーバーやビルドは不要で、`index.html` をブラウザで開くだけで使えます。

## 表示内容

| パネル | 内容 | データ提供元 |
| --- | --- | --- |
| 時計 | 年月日・曜日・時分秒（和暦、祝日名も表示） | 祝日: [holidays-jp](https://holidays-jp.github.io/) |
| 現在の天気 | 天気・気温・体感・湿度・風・降水量・日の出／日の入 | [Open-Meteo](https://open-meteo.com/)（気象庁モデル） |
| 直近12時間の予報 | 1時間ごとの天気・気温、6時間ごとの降水確率 | Open-Meteo（気象庁モデル）、降水確率は[気象庁](https://www.jma.go.jp/bosai/forecast/) |
| 週間天気予報 | 今日から8日分の天気・最高／最低気温・降水確率 | Open-Meteo（気象庁モデル）、降水確率は気象庁 |
| ニュース | ジャンル別の見出し（日経・読売・産経・CNN） | [wor.jp](https://assets.wor.jp/) の RSS、CNN.co.jp の RSS |
| 生成AIニュース（任意） | 生成AIに関する見出し | 上記に加え CNET Japan・ZDNET Japan・WIRED.jp の RSS |
| ITテックニュース（任意） | IT・テクノロジーの見出し | CNET Japan・ZDNET Japan・WIRED.jp、日経・読売のテクノロジー面の RSS。ITmedia NEWS・Publickey は中継サーバー経由 |
| マーケット | 日経225先物、ドル/円、NYダウ、S&P500、NASDAQ100 など | [TradingView](https://jp.tradingview.com/) ウィジェット |

現在地はブラウザの位置情報から取得し、地名は [BigDataCloud](https://www.bigdatacloud.com/) で調べます。位置情報が使えない場合は東京を表示します。

Open-Meteo の天気・気温は、気象庁の数値予報モデル（`models=jma_seamless`：直近はメソモデル MSM、その先は全球モデル GSM）の値を使います。標準の `best_match` は地点によって気象庁以外のモデルを選ぶため、明示的に指定しています。

### 降水確率について

降水確率は、テレビなどと同じ気象庁の予報を表示します（1mm 以上の降水がある確率）。

- 直近12時間の予報: 6時間ごと（0–6／6–12／12–18／18–24時）の値を、該当する時間の欄にまたがる帯で表示します。発表済みの予報に含まれない時間帯は「—」です。
- 週間天気予報: 今日・明日は6時間ごとの値を「0/0/20/20%」の形で、それ以降は1日の値を表示します。8日目は気象庁の週間予報の対象外のため「-」です。
- 地点は [国土地理院の逆ジオコーダー](https://maps.gsi.go.jp/development/reverse_geocoder.html) で市区町村を調べ、気象庁の予報区（例: 東京地方、神奈川県 東部）に対応づけます。逆ジオコーダーは応答に時間がかかることがあるため、結果は地点ごとにブラウザへ保存します。
- 日本国外の地点や、気象庁の予報を取得できないときは Open-Meteo の値（1時間ごとの 0.1mm 以上の降水確率、週間は1時間ごとの最大値。気象庁モデルには降水確率がないため、標準モデルの値）を表示します。どちらを表示しているかは各パネル右上と「現在の天気」の下に出ます。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Firefox / Safari の最新版）で開きます。
2. 位置情報の利用を確認されたら「許可」を選びます。
3. 時計パネル右上の ⚙ から設定を変更できます。▦ でレイアウト編集、⛶ で全画面表示、⟳ ですべて更新します。

## 生成AIニュース

生成AIに関するニュースだけを集めるパネルです。最初は表示されていないので、⚙設定の「生成AIニュースのパネルを表示する」にチェックを入れるか、▦ レイアウト編集の下部に出る「＋ 生成AIニュース」を押して追加します。自動レイアウトのまま追加した場合は、ニュースの欄を分け合う配置になり、1画面に収まります。

主要紙（ニュースの「提供元」で選んだもの）と CNET Japan・ZDNET Japan・WIRED.jp の見出しから、生成AI、ChatGPT、OpenAI、Claude、LLM、AIエージェントなどのキーワードを含む記事を新しい順に表示します。キーワードは⚙設定で変更できます。

## ITテックニュース

IT・テクノロジーのニュースだけを並べるパネルです。生成AIニュースと同じく、⚙設定の「ITテックニュースのパネルを表示する」か、▦ レイアウト編集の「＋ ITテックニュース」で追加します。

CNET Japan・ZDNET Japan・WIRED.jp と、日経・読売のテクノロジー面の見出しを新しい順に表示します（キーワードでの絞り込みはしません）。表示する提供元は⚙設定で選べます。

### ITmedia NEWS・Publickey（中継サーバーが必要）

ITmedia NEWS と Publickey のフィードはブラウザから直接読み込めない（CORS に対応していない）ため、自分で用意した中継サーバーを経由して取得します。中継サーバーの URL が未設定の間、この2つは表示されません。

中継サーバーは [Cloudflare Workers](https://workers.cloudflare.com/) の無料プランで動かせます。

1. Cloudflare のアカウントを作成し、ダッシュボードの「Workers & Pages」→「作成」→「Worker を作成」で新しい Worker を作ります（名前は例えば `feed-relay`）。
2. 「コードを編集」を開き、中身を [relay/cloudflare-worker.js](relay/cloudflare-worker.js) の内容に置き換えて「デプロイ」します。
3. 表示された URL（例: `https://feed-relay.<アカウント名>.workers.dev/`）を、⚙設定の「ITテックニュース」→「中継サーバー」に入力し、「接続を確認」で記事を取得できることを確かめてから保存します。

中継サーバーは `?url=<フィードのURL>` で指定したフィードを取得し、CORS のヘッダーを付けて返します。誰でも任意のサイトを取得できる踏み台にならないよう、中継するのはスクリプト先頭の `ALLOWED_HOSTS` にあるホスト（ITmedia と Publickey）だけです。取得結果は5分間キャッシュします。

自動レイアウトのまま追加パネルを表示すると、ニュースの欄（1920×1080 では2つ目をマーケットの下）を分け合う配置になります。1280×800 では追加パネル1つまでが1画面に収まり、2つとも表示すると縦にスクロールします。

## レイアウトの編集

▦ を押すと編集モードになり、パネルごとに次の操作ができます。

- **移動**: パネルをドラッグして、ほかのパネルの左半分／右半分に重ねると、その前／後ろに移動
- **サイズ変更**: パネル右下の角をドラッグ、または「幅−／幅＋／高さ−／高さ＋」ボタン。画面を横12列・縦12行に分けた単位で指定します（縦12行で画面の高さちょうど）
- **非表示**: 「非表示」ボタン。隠したパネルは下部のバーに表示され、押すと元に戻ります
- **完了**: 「完了」または Esc キーで編集を終了します。変更はその場で保存されます

「自動レイアウトに戻す」で、画面サイズに合わせた標準の配置（1920×1080 や 1280×800 で1画面に収まる配置）に戻ります。
幅 900px 未満の画面では、編集したレイアウトでも1列に並び、並び順と表示／非表示だけが反映されます。

## 設定でできること

- **天気の地点**: 現在地の自動取得か、地名検索（国土地理院 地名検索API）で地点を指定
- **テーマ**: OS の設定に合わせる／ダーク／ライト
- **ニュース**
  - 表示するジャンルの選択と並べ替え（主要・政治・経済・ビジネス・マーケット・国際・社会・テクノロジー・スポーツ・エンタメ・文化・ライフ）
  - キーワードタブの追加（全ジャンルの記事から、スペース区切りのいずれかの語を含む見出しを表示）
  - 任意の RSS フィードの追加
  - 提供元（日経・読売・産経・CNN）の選択、表示件数、タブの自動切替
- **生成AIニュース**: パネルの表示／非表示と、見出しの絞り込みに使うキーワード（1行に1つ）
- **ITテックニュース**: パネルの表示／非表示、表示する提供元、中継サーバーの URL（ITmedia NEWS・Publickey 用）
- **マーケット**: 表示する銘柄の追加・削除・並べ替え（先頭がメイン表示）。チャートの期間（1日／1か月／1年）はパネル上で切り替え

設定はブラウザの localStorage に保存されます（ブラウザごと・端末ごと）。

## 注意事項

- 天気・ニュース・株価の取得にはインターネット接続が必要です。
- ブラウザから直接読み込める（CORS に対応した）データ元だけを使っています。RSS を追加する場合も CORS 対応のフィードしか表示できません（例: Yahoo!ニュースや Google ニュースの RSS は表示できません）。
- 日経平均株価（現物指数）は TradingView のウィジェットで配信されていないため、日経225先物（大阪取引所）を表示しています。公式値は [日経平均プロフィル](https://indexes.nikkei.co.jp/nkave) を参照してください。
- 株価は遅延している場合があります。投資判断には使わないでください。
- `file://` で開いたときに位置情報が取得できないブラウザでは、設定で地点を指定してください。

## ファイル構成

```
index.html        画面
css/style.css     スタイル（ライト／ダークテーマ）
js/config.js      ニュースのジャンル・フィード、銘柄プリセット、初期設定
js/util.js        共通処理（取得、設定の保存・読み込み）
js/clock.js       時計・祝日
js/jma.js         気象庁の降水確率（予報区の特定と取得）
js/weather.js     現在地・天気
js/news.js        ニュース
js/ainews.js      生成AIニュース
js/technews.js    ITテックニュース
js/market.js      マーケット
js/settings.js    設定ダイアログ
js/layout.js      レイアウト（表示／非表示・並び順・サイズ）と編集モード
js/main.js        起動処理
relay/cloudflare-worker.js  ITmedia NEWS・Publickey を取得する中継サーバー（Cloudflare Workers 用）
```

`file://` でも動くよう、ES Modules は使わず通常の `<script>` で読み込んでいます。
