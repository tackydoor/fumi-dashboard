# MyDashboard

ブラウザだけで動くダッシュボードです。サーバーやビルドは不要で、`index.html` をブラウザで開くだけで使えます。

## 表示内容

| パネル | 内容 | データ提供元 |
| --- | --- | --- |
| 時計 | 年月日・曜日・時分秒（和暦、祝日名も表示） | 祝日: [holidays-jp](https://holidays-jp.github.io/) |
| 現在の天気 | 天気・気温・体感・湿度・風・降水量・日の出／日の入 | [Open-Meteo](https://open-meteo.com/) |
| 直近12時間の予報 | 1時間ごとの天気・気温・降水確率 | Open-Meteo |
| 週間天気予報 | 今日から8日分の天気・最高／最低気温・降水確率 | Open-Meteo |
| ニュース | ジャンル別の見出し（日経・読売・産経・CNN） | [wor.jp](https://assets.wor.jp/) の RSS、CNN.co.jp の RSS |
| マーケット | 日経225先物、ドル/円、NYダウ、S&P500、NASDAQ100 など | [TradingView](https://jp.tradingview.com/) ウィジェット |

現在地はブラウザの位置情報から取得し、地名は [BigDataCloud](https://www.bigdatacloud.com/) で調べます。位置情報が使えない場合は東京を表示します。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Firefox / Safari の最新版）で開きます。
2. 位置情報の利用を確認されたら「許可」を選びます。
3. 右上の ⚙ から設定を変更できます。⛶ で全画面表示、⟳ ですべて更新します。

## 設定でできること

- **天気の地点**: 現在地の自動取得か、地名検索（国土地理院 地名検索API）で地点を指定
- **テーマ**: OS の設定に合わせる／ダーク／ライト
- **ニュース**
  - 表示するジャンルの選択と並べ替え（主要・政治・経済・ビジネス・マーケット・国際・社会・テクノロジー・スポーツ・エンタメ・文化・ライフ）
  - キーワードタブの追加（全ジャンルの記事から、スペース区切りのいずれかの語を含む見出しを表示）
  - 任意の RSS フィードの追加
  - 提供元（日経・読売・産経・CNN）の選択、表示件数、タブの自動切替
- **マーケット**: 表示する銘柄の追加・削除・並べ替え（先頭がメイン表示）。チャートの期間（1日／1か月／1年）はパネル上で切り替え

設定はブラウザの localStorage に保存されます（ブラウザごと・端末ごと）。

## 注意事項

- 天気・ニュース・株価の取得にはインターネット接続が必要です。
- ブラウザから直接読み込める（CORS に対応した）データ元だけを使っています。RSS を追加する場合も CORS 対応のフィードしか表示できません（例: Yahoo!ニュースや Google ニュースの RSS は表示できません）。
- 日経平均株価（現物指数）は TradingView のウィジェットで配信されていないため、日経225先物（大阪取引所）を表示しています。公式値は [日経平均プロフィル](https://indexes.nikkei.co.jp/nkave) を参照してください。
- 株価は遅延している場合があります。投資判断には使わないでください。
- `file://` で開いたときに位置情報が取得できないブラウザでは、設定で地点を指定してください。

## ファイル構成

```
index.html        画面
css/style.css     スタイル（ライト／ダークテーマ）
js/config.js      ニュースのジャンル・フィード、銘柄プリセット、初期設定
js/util.js        共通処理（取得、設定の保存・読み込み）
js/clock.js       時計・祝日
js/weather.js     現在地・天気
js/news.js        ニュース
js/market.js      マーケット
js/settings.js    設定ダイアログ
js/main.js        起動処理
```

`file://` でも動くよう、ES Modules は使わず通常の `<script>` で読み込んでいます。
